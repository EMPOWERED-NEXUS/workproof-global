# WorkProof Global

WorkProof Global is a portable proof-of-work platform that helps informal workers, freelancers, artisans, caregivers, and small service businesses create client-confirmed records of completed work, demonstrated skills, and income activity.

## Core Innovation

The Verified Work Receipt transforms completed work into portable, verifiable evidence controlled by the worker.

## Project Status

Phase 0: Project foundation.

## Applications

- apps/web: React and TypeScript frontend
- apps/api: Node.js, Express, and TypeScript backend
- packages/shared: Shared types and validation
- docs: Architecture and project documentation
